# Annotation guidelines

Status: **bootstrap draft**

This file will document Hawrami-specific decisions for linguistic annotation and Universal Dependencies.

Topics that need explicit treatment include:

- tokenization;
- lemma conventions;
- UPOS;
- clitics;
- pronouns;
- copular constructions;
- auxiliaries;
- case;
- gender;
- number;
- person;
- tense;
- aspect;
- mood;
- alignment / ergativity where relevant;
- possession;
- adpositions;
- complex predicates;
- coordination;
- subordination;
- punctuation.

Each non-obvious convention should include:

1. the decision;
2. linguistic rationale;
3. attested examples;
4. the corresponding UD relation or feature where applicable.
