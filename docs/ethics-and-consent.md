# Ethics and consent

Language documentation should protect speakers as well as preserve language data.

## Minimum requirements

- Do not publish recordings or personal data without a clear permission basis.
- Use anonymized speaker IDs by default.
- Record whether a contributor wants public attribution.
- Avoid collecting unnecessary sensitive personal information.
- Make withdrawal and correction procedures clear for elicited material.

## Consent status

Suggested controlled values for `consent_status`:

- `pending`
- `private-only`
- `public-text`
- `public-text-audio`
- `public-attributed`

These are project workflow labels, not legal advice. The maintainers should adapt them to the actual consent process used.
