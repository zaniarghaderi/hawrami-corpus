# Licensing

Status: **decision pending**

Do not assume that all corpus layers can use the same license.

Possible components include:

- original texts;
- elicited transcriptions;
- translations;
- annotations;
- metadata;
- audio recordings;
- scripts and documentation.

Before the first public data release, the maintainers should document:

1. who owns or controls each data source;
2. what permission was granted;
3. which open license, if any, applies;
4. whether the intended license is compatible with Universal Dependencies.

The repository currently does not declare a corpus-data license.
