# Orthography

Status: **draft / not yet standardized**

This document will record the project's orthographic policy for Hawrami.

Decisions to document include:

- script and character inventory;
- Unicode normalization;
- treatment of Arabic vs. Persian code points;
- spacing and zero-width non-joiner;
- punctuation;
- clitics;
- compounds;
- loanwords;
- representation of dialectal variation;
- relationship between original and normalized forms.

## Principle

Preserve the original form exactly in `text_original`. Any project-wide normalization belongs in `text_normalized` and must be documented here.
